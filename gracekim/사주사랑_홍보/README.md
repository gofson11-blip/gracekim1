## 진행 순서
1. **테스트 2주 동안**: 계정을 만들고 운세 콘텐츠로 팔로워 모으기 (앱 링크 없음)
2. **정식 출시 직후**: 프로필 링크에 플레이스토어 주소를 넣고 본격 홍보
3. 가능하면 출시를 **12월 말~1월 신년운세 시즌**에 맞추기

## 공통 주의사항
- 모든 영상 하단에 **"재미로 보는 운세입니다"** 표기
- 공포심을 주는 표현, 건강·투자·결혼을 단정하는 조언은 피하기
- 배경음악은 각 플랫폼 제공 음원만 사용
- 댓글 작성자의 닉네임과 전체 생년월일은 가리고 키워드만 노출
- 가짜 후기·별점 금지, 유료로 홍보를 맡길 경우 상대방은 "유료 광고 포함" 표시 필요

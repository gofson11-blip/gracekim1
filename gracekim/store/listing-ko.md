### 데이터 보안 양식 (Data safety) 답변 초안

AdMob(Google Mobile Ads SDK) 사용 기준의 일반적인 답변입니다. 제출 전 Google의 최신 AdMob 데이터 공개 안내를 한 번 더 확인하세요.

- 앱이 사용자 데이터를 수집하거나 공유하나요? → **예** (광고 SDK 때문)
- 수집되는 데이터 유형
  - **기기 또는 기타 ID** (광고 ID) — 수집 · 공유 / 목적: 광고 또는 마케팅, 분석, 사기 방지·보안
  - **앱 활동 · 앱 상호작용** — 수집 / 목적: 광고, 분석
  - **앱 정보 및 성능 · 비정상 종료 로그, 진단** — 수집 / 목적: 분석, 사기 방지
  - **위치 · 대략적인 위치** (IP 기반) — 수집 / 목적: 광고, 사기 방지
- 전송 중 데이터 암호화 → **예**
- 사용자가 데이터 삭제를 요청할 수 있나요? → 앱 자체는 데이터를 저장하지 않음 (광고 ID는 기기 설정에서 재설정·삭제 가능)
- 이름·생년월일시 → **수집하지 않음** (기기 안에서만 처리, 전송하지 않음)

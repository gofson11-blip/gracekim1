# 오늘의 사주 (Android)

생년월일시를 입력하면 사주팔자, 오행 분포, 십신, 대운, 올해 운세를 보여 주는 Android 앱입니다.

## 기능
- 양력 / 음력(윤달 포함) 입력, 시간 모름 지원
- 절기(입춘 등) 기준 년주·월주, 일주, 시주 계산
- 서울 기준 진태양시 보정(-32분) 선택, 23시(자시)부터 다음 날 일주 적용
- 오행 분포 차트와 부족·과다 오행 조언
- 십신, 일간(나)의 성격 풀이, 간이 신강/신약 판정
- 대운(10년 단위, 순행/역행)과 올해 세운 풀이
- 인터넷 연결 없이 기기 안에서 모두 계산 (외부 API·비용 없음)

## 구조
- `saju-core/` — 순수 Kotlin 사주 계산 엔진 (천문 계산으로 절기·합삭·음력 변환, 1900~2100년)
- `app/` — Jetpack Compose 화면

## 빌드
Android Studio에서 `gracekim` 폴더를 열고 실행하면 됩니다.

명령줄:
```bash
./gradlew :app:assembleDebug
```

계산 엔진만 테스트 (Android SDK 불필요):
```bash
./gradlew :saju-core:test -PskipApp=true
```

GitHub에 푸시하면 GitHub Actions가 APK를 빌드합니다. Actions 실행 결과 페이지의 **Artifacts**에서 `saju-app-debug-apk`를 내려받아 휴대폰에 설치할 수 있습니다.

## 참고
- 절기 시각은 천문 공식으로 계산하며 오차는 대략 수 분 이내입니다. 절기 경계 몇 분 안에 태어난 경우 만세력과 다를 수 있습니다.
- 한국의 과거 서머타임(1948~1960, 1987~1988)은 자동 보정하지 않습니다.
- 풀이는 전통 명리학 이론에 따른 참고용입니다.

# 템노리 SNS 말투 가이드 (11/12 사장님 지시: "AI처럼 말고 친근하게")
모든 SNS 글은 제작 담당이 작성·예약한다. 아래 규칙을 따른다.

## 이렇게 쓴다
- 친구한테 카톡하듯이: ~요/~구요/~더라구요, ㅎㅎ ㅋㅋ ㅠ .. 자연스럽게
- 첫 줄은 공감 질문이나 혼잣말: "이불 털 때마다 재채기 나는 분들 손 🙋"
- 한 문장은 짧게, 줄바꿈 자주
- 이모지는 글 하나에 2~3개까지
- 마지막엔 댓글 유도 질문 하나
- 해시태그는 5~6개

## 이렇게 안 쓴다 (AI 티 나는 것)
- ✔️ 체크리스트, "1. 2. 3." 딱딱한 번호 나열 (꼭 필요할 때만)
- 긴 줄표(—), 화살표(→), 괄호 설명 남발
- "~입니다", "~할 수 있습니다", "완벽한", "혁신적인", "필수템" 같은 광고 문구
- 모든 문장 길이·구조가 똑같은 글

## 지켜야 하는 것 (말투보다 우선)
- 쿠팡 파트너스 문구 / [광고] 표시는 그대로 유지
- 상품을 직접 써본 것처럼 쓰지 않는다 ("써봤는데", "제가 쓰는")
  → "후기가 많더라구요", "많이들 쓰시던데"처럼 사실 범위에서 표현
  (사장님이 실제로 써보신 상품만 1인칭 후기 가능)
- 확인 안 된 수치·효과(살균 %, 완벽 제거 등) 금지

## 운영 원칙
- 게시: **월·수·금 낮 12시**, 인스타그램·틱톡·스레드 동시 (Metricool 예약)
- 분야: 살림·청소·주방 생활꿀템 유지
- 가격 배치: **월·수 = 1~5만 원대 충동구매템**, **금 = 10만 원 이상 고가템**(수수료 확보)
- 시즌 흐름: 11월 중순 김장·겨울 대비 → 11월 말 블랙프라이데이 → 12월 연말 대청소 → 크리스마스 선물 → 새해 정리
- 상품 선정 기준: 로켓배송, 별점 4.5 이상, 리뷰 1,000개 이상(고가템은 300개 이상), 최근 한 달 구매자 표시 있는 상품
- 아래는 **상품 유형**이며, 실제 쿠팡 상품과 파트너스 링크는 회차별로 사장님이 골라 보내주시면 확정

## 제작 비용 계획 (일레븐랩스)
- 3회차 실제 비용 6,488 크레딧 → 회차당 비용 절감 필요 (잔액 약 65,000)
- 기본 구성안 (회차당 약 4,000 크레딧)
  - 후킹 영상 1개: 약 2,121
  - 장면 이미지 3장: 저가 모델(Gemini 3.1 Flash Image, 상품 참고 이미지 포함) 장당 609 → 1,827
  - 내레이션: 약 100
- 절약안 (회차당 약 2,000 크레딧): 후킹 영상 대신 이미지 4장 + 확대 효과
- 22·24회차는 기존 영상 재편집이라 0 크레딧
- 21회 전체 예상: 기본안 약 76,000 / 절약안 약 40,000 → **월·수 저가템은 절약안, 금 고가템은 기본안** 혼합 시 약 55,000 (12월 크레딧 충전 전제)
- 모든 회차: 생성 전 실제 조건(참고 이미지 포함)으로 견적 → 사용자 승인 후 제작
